# Summary

## Getting Started

### Definition

- Axios: promised-based HTTP Client for nodejs and browser.
- Use nodejs http module on server-side, XMLHttpRequest on client (browser).

### Features

- Make XMLHttpRequest, http request.
- Support Promise API.
- Intercept, transform req and res; cancle req, timeout.
- Auto req body serialization: JSON, Multipart/FormData, URL encoded form.
- Auto JSON Data handling.
- Extra info (speed rate, remaining time), set bandwidth limit.
- Protect XSRF.

## Request Config

- url, method, baseUrl, headers, params, data, timeout, responseType, withCredentials

## Config Defaults

- Global axios defaults
  axios.default.<option>=
  axios.defaults.headers.common[field]=
  axios.defaults.headers.post[field]=
- Custom instance defaults
  instance.defaults.

## Interceptors

- Intercept request or responses before they handled by then or catch.
- use: add a handler to list of handlers to be run when Promise fulfilled or rejected.
  axios/instance.interceptors.request/response.use(async fulfilled_function(return Promise), async reject_function(return Promise), {synchronous: true, runwhen: () => {return true}})

## Axios Instance

- Create a new instance of axios with a custom config
- Create instance axios
  axios.create(config)
- Instance methods: used with instance method
  .request(config), get(url), delete(url, config), post(url, conif), put(url, data)
- Create function:
  const function_name = async (apiRequest: TypeRequest): Promise<TypeResponse> => { await axios instance methods}

## Handling Errors

- error structure: messsage, name, stack, config, code, status
- .get...().catch(error => {})

## Cancellation

- Setting timeout in axios call handles related timeouts
- signal: AbortController
- .get(url, {signal: AbortSignal.timeout()})

## URL Encoding Bodies

- By default, axios serializes JS objects to JSON. To send data in application/x-www-form-unlencoded format:
- new UrlSearchParams
